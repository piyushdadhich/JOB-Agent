DIMENSION DEFINITIONS:

FUNCTION (most important):
Does the day-to-day work match what the candidate has done?
0 = No functional overlap; the work is something candidate
    has not done
1 = Tangential overlap; some skills transfer but core work
    is new
2 = Substantive overlap; most of the work is similar to
    candidate's experience
3 = Direct match; this IS the work the candidate has been
    doing

Note: A posting at a financial services company is not
automatically a function match for a candidate with financial
services experience. Function is about the WORK ITSELF, not
the industry.

Note: When a posting's title and responsibilities directly match
a role the candidate has held - e.g. Senior Project Manager /
Senior Delivery Lead / Senior Product Manager / Senior Product
Owner / Scrum Master with end-to-end delivery accountability -
the function score is 3, regardless of industry. Industry
match is captured in the DOMAIN dimension below; do not penalize
function for industry mismatch.

DOMAIN:
Is the industry/sector compatible with the candidate's
background?
0 = Wrong industry, no transferable exposure
1 = Adjacent industry, some transfer
2 = Industry the candidate has worked in
3 = Exact sub-sector match

SENIORITY:
Does the role's level match the candidate's experience?
0 = Wrong level (entry-level OR executive when candidate is
    mid-senior)
1 = One level off
2 = Same band, slightly different scope
3 = Direct seniority match

DISQUALIFIER:
Hard mismatches that should kill an otherwise promising rating:
- Required certification or license candidate lacks (BlackLine,
  CPA, PE, etc.)
- Required language proficiency candidate lacks
- Hard geo requirement (in-person at non-target city, no remote)
- Required years in specific tool candidate has not used
